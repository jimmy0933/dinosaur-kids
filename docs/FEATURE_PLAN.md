# 恐龍探險島：4 歲兒童遊戲規劃

## 核心目標

一個讓不識字的小朋友也會玩的恐龍世界。玩家透過**看圖、聽語音、點一下**學會辨識不同恐龍。每次操作都有鼓勵，沒有倒數、扣分、廣告、登入與社交功能。

## 主畫面 / 導航

- 橫向全螢幕、童趣森林背景，操作集中在六個大圖示。
- `📖 恐龍圖鑑`：瀏覽角色，觸控肉食/草食/雜食分類。
- `🌴 森林探險`：點開樹叢找到隱藏角色。
- `🥬 餵食恐龍`：挑選植物或肉類，學習食性；錯誤沒有負評。
- `🦴 挖挖化石`：連點五下，恐龍逐漸現身。
- `❓ 猜猜恐龍`：說出角色名稱，三選一視覺辨識。
- `⭐ 收藏貼紙`：收集已探索的恐龍，離線保存。

上方固定：回首頁、目前園區、收集數量、重播語音、設定。

## 恐龍角色圖鑑

V1 先做 18 種著名恐龍，插畫各有不同花色與身體特徵：

暴龍、三角龍、劍龍、腕龍、甲龍、伶盜龍、棘龍、副櫛龍、異特龍、梁龍、厚頭龍、鐮刀龍、食肉牛龍、禽龍、慈母龍、竊蛋龍、雙冠龍、迷惑龍。

每隻卡片都有中英文名稱、🌿🍖🥚 食性、📏 身高、⚖️ 體重，以及一句 4 歲孩子聽得懂的特徵解說。資料用約略值，不直接搬用《侏羅紀世界：適者生存》混種角色的戰鬥數值。

## 語音與介面

- Android 原生 TextToSpeech，預設繁體中文，可切換英語，調節速度或關閉。
- 進入恐龍明細、進入遊戲、開始下一題時盡可能自動朗讀；按喇叭重播。
- 一個畫面只給一種明確主行動，大圖、大按鍵；不需要讀長段文字。
- 顏色：森林綠、奶油白、珊瑚橘、陽光黃。插圖具備物種差異而不是一種模板。
- 不用 WebView，不需網路權限。互動皆在本機完成。

## 已實作 V1 與下一階段

**V1 原始碼**：主畫面、圖鑑、角色明細、四種小遊戲、收藏冊、語音切換、進度存檔、原創插畫、GitHub Actions 簽章與 latest release 工作流程。

**V2 可選擴充**：恐龍寶寶照顧（擦洗、餵食）、足跡配對、不同棲地地圖、更多插圖細節與專屬動作動畫、親子一鍵播放故事。

**V3 可選擴充**：溫和賽跑、簡單的兩隻恐龍互動、恐龍蛋孵化；原則上不採用激烈戰鬥或不適合幼兒的商城設計。
